
# API Guide

Here is our guide to Appshare API, access your account data as JSON results from https requests,

### List of topics

- Get an API token
- Download, use Postman
- Access all your account resources

#### API Token
 
Access Appshare admin web interface to get your API token

#### Download, use Postman
 
Download Postman http client at [postman.com](https://www.postman.com)

Install it and continue with the API guide.

#### Access all your account resources

Add the API token as Authorization header in Postman.

Request your account at [api/v1/accounts](https://api.appshare.site/api/v1/accounts.json)
