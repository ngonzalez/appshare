#### Aplicaciones de escritorio

Usamos un cliente de macOS y un cliente de Windows para subir archivos a nuestros servidores: inicia sesión, sube tus carpetas (archivos de hasta 5000 MiB cada una), publicaslas, previsualiza sus archivos e invita a tu equipo.

Requisitos mínimos de configuración:

| Mac | PC |
|-------------------------------------------|-----------------------|
| MacBook Pro (2020 M1 y posteriores) | ***CPU:*** Core i5 |
| ***RAM:*** 18GB | ***RAM:*** 32GB |
| ***sistema operativo:*** macOS Sequoia o Tahoe | ***OS:*** Windows 11 |
