#### Applications de bureau

Nous utilisons un client macOS et un client Windows pour télécharger les fichiers sur nos serveurs : connectez-vous, téléchargez vos dossiers (jusqu’à 5000 Mo chacun), publiez-les, prévisualisez leurs fichiers et invitez votre équipe.

Exigences minimales de configuration :

| Mac | PC |
|-------------------------------------------|-----------------------|
| MacBook Pro (2020 M1 et versions ultérieures) | ***CPU :*** Core i5 |
| ***RAM :*** 18 Go | ***RAM :*** 32 Go |
| ***OS :*** macOS Sequoia ou Tahoe | ***OS :*** Windows 11 |
