
# Appshare-Dokumentation

Appshare veröffentlicht Ihre Medien und Dokumente auf Ihrer eigenen Website: Fotos, Videos, Musik, PDFs und Textdateien, organisiert in Ordnern, zu **your-name.appshare.site**.

- Lade deine Dateien mit der **Desktop-Anwendung** für macOS oder Windows hoch
- Organisieren und veröffentlichen Sie sie und richten Sie Ihre Website im **Webadmin** ein
- Lade dein Team ein: Jedes Konto hat eigene Nutzer
- Lesen Sie die Daten Ihres Kontos als JSON mit der **API**

### Wo soll ich anfangen

- [Schneller Start](https://register.appshare.site/documentation#quick-start): Erstellen Sie Ihr Konto und veröffentlichen Sie Ihren ersten Ordner
- Installieren Sie die Desktop-Anwendung: [macOS](https://register.appshare.site/documentation#install-macos) oder [Windows](https://register.appshare.site/documentation#install-windows)
- [Webanwendung](https://register.appshare.site/documentation#web-application): Ihre Website und ihr Administrator
- [API-Leitfaden:](https://register.appshare.site/documentation#api-guide) Die Daten deines Kontos aus HTTPS-Anfragen

Der Stand unserer Dienstleistungen wird in [status.appshare.site](https://status.appshare.site) dargestellt.
