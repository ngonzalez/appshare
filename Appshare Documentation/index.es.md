
# Documentación de AppShare

Appshare publica tus medios y documentos en tu propia página web: fotos, vídeos, música, PDFs y archivos de texto, organizados en carpetas, en **your-name.appshare.site**.

- Sube tus archivos con la **aplicación de escritorio** para macOS o Windows
- Organízalos y publícalos, y configura tu sitio web en **la administración web**
- Invita a tu equipo: cada cuenta tiene sus propios usuarios
- Lee los datos de tu cuenta como JSON con la **API**

### Por dónde empezar

- [Inicio rápido](https://register.appshare.site/documentation#quick-start): crea tu cuenta y publica tu primera carpeta
- Instala la aplicación de escritorio: [macOS](https://register.appshare.site/documentation#install-macos) o [Windows](https://register.appshare.site/documentation#install-windows)
- [Aplicación web](https://register.appshare.site/documentation#web-application): tu sitio web y su administrador
- [Guía API](https://register.appshare.site/documentation#api-guide): los datos de tu cuenta procedentes de peticiones https

El estado de nuestros servicios se muestra [en status.appshare.site](https://status.appshare.site).
