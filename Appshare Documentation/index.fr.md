
# Documentation Appshare

Appshare publie vos médias et documents sur votre propre site web : photos, vidéos, musiques, PDF et fichiers texte, organisés dans des dossiers, à **your-name.appshare.site**.

- Téléchargez vos fichiers avec **l’application de bureau** pour macOS ou Windows
- Organisez-les et publiez-les, et créez votre site web dans **l’administration web**
- Invitez votre équipe : chaque compte a ses propres utilisateurs
- Lisez les données de votre compte en JSON avec **l’API**

### Par où commencer

- [Démarrage rapide](https://register.appshare.site/documentation#quick-start) : créez votre compte et publiez votre premier dossier
- Installez l’application de bureau : [macOS](https://register.appshare.site/documentation#install-macos) ou [Windows](https://register.appshare.site/documentation#install-windows)
- [Application web](https://register.appshare.site/documentation#web-application) : votre site web et son administrateur
- [Guide API](https://register.appshare.site/documentation#api-guide) : les données de votre compte issues des requêtes https

L’état de nos services est affiché [à status.appshare.site](https://status.appshare.site).
