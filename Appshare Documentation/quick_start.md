
# Quick start

Quick start into Appshare applications

### List of topics

 - Download and install the app.
 - Create our first upload and publish it.

#### Desktop Applications

We use a macOS client and a Windows client to upload files on our servers.

Configuration minimum requirements:

|  Mac                                      | PC                                       |
|:-----------------------------------------:|:----------------------------------------:|
| MacBook Pro (2020 M1 and later)           |     ***CPU:*** Core i5                   |
|     ***RAM:*** 18GB                       |     ***RAM:*** 32GB                      |
|     ***OS:*** macOS Sequoia or Tahoe      |     ***OS:*** Windows 11                 |
