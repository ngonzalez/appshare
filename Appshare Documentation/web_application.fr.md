# Application web

Votre site web, et l’administrateur où vous l’avez configuré

### Liste des sujets

- Votre site web
- Connexion à l’administration
- L’administration
- Vos dossiers et leur publication
- Votre forfait et votre abonnement

#### Votre site web

Votre site web est à **your-name.appshare.site**, l’adresse que vous avez choisie lors de la création de votre compte : n’importe qui peut voir ses dossiers publiés, les rechercher et lire ses fichiers. Il fonctionne avec Google Chrome, Apple Safari, Microsoft Edge et Firefox.

<br />

![img](https://api.appshare.site/attachment/screenshot-2026-10-25-at-2-e9aafb12)

#### Connexion à l’administration

Cliquez sur le bouton administrateur en bas de votre site web, puis connectez-vous avec votre adresse e-mail et votre mot de passe.

<br />

![img](https://api.appshare.site/attachment/screenshot-2026-10-25-at-2-47902e84)

#### L’administration

Les onglets de l’administrateur configurent votre site web :

- **Thèmes** : les logos et les couleurs de votre site, pour ses thèmes clair et sombre
- **Méta-tags** : les tags que les moteurs de recherche et les réseaux sociaux lisent sur vos pages
- **Liens** : les liens dans le pied de page de vos pages
- **Exportez** : vos dossiers, fichiers et événements sous forme de fichiers CSV ou Excel
- **Statistiques** : graphiques des visites et téléchargements de vos pages
- **Téléchargements** : ce qui a été mis en ligne, jour après jour
- **Utilisation** : votre forfait, la quantité de stockage de vos fichiers, vos utilisateurs et votre abonnement
- **Identifiants** : les adresses de votre site web, votre jeton API et les paramètres de l’outil en ligne de commande

<br />

![img](https://api.appshare.site/attachment/screenshot-2026-10-25-at-2-44652e63)

#### Vos dossiers et leur publication

Changez les noms et tags de vos dossiers, ainsi que leur publication : publiés (toujours, ou entre deux dates), archivés ou créés (visibles uniquement par les utilisateurs de votre compte).

<br />

![img](https://api.appshare.site/attachment/screenshot-2026-10-25-at-2-471fe0e3)

#### Votre forfait et votre abonnement

**L’onglet Utilisation** affiche votre forfait, le stockage que prennent vos fichiers et vos utilisateurs. « Gérer la facturation » ouvre votre abonnement sur Stripe : changez votre forfait ou votre carte, lisez vos factures ou annulez.
